# Auditoria de Usuários em Grupo do Active Directory

Este script permite realizar uma auditoria completa dos usuários do **Microsoft Active Directory (AD)** com base na associação a um grupo específico.

A ferramenta identifica quais usuários pertencem e quais não pertencem ao grupo informado, fornecendo uma visão clara para processos de governança, conformidade, revisão de acessos e validação de permissões.

## Funcionalidades

- Consulta membros de um grupo do Active Directory.
- Identifica usuários que fazem parte do grupo analisado.
- Identifica usuários que não fazem parte do grupo analisado.
- Gera informações para auditoria e controle de acessos.
- Auxilia em revisões periódicas de permissões e conformidade.
- Fácil execução e personalização.

## Casos de Uso

- Auditoria de acessos.
- Revisão periódica de grupos de segurança.
- Validação de permissões antes de auditorias internas ou externas.
- Identificação de usuários sem a associação necessária a um grupo.
- Governança e conformidade em ambientes corporativos.

## Requisitos

- Windows PowerShell
- Active Directory Module for Windows PowerShell
- Permissão para consulta ao Active Directory
